# 图片拼图游戏

基于 **Vue 3 + Vite** 的纯前端图片拼图游戏，无需后端服务。

## 功能

- 📷 上传本地图片，上传后直接开始游戏
- 🎚️ 难度可选 3×3 / 4×4 / 5×5，切换难度自动重新分割打乱
- 🔀 拼图块随机打乱，支持**点击交换**与**拖动交换**（手机/电脑均可）
- ⏱️ 实时计时、步数统计，完成后弹窗提示成绩
- 🔁 支持重新开始、重新上传图片、随时切换难度
- 📱 响应式布局，适配手机与电脑

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173 ）。

## 构建

```bash
npm run build
npm run preview
```

## 玩法

1. 点击上传区域选择一张本地图片。
2. 选择难度（默认 3×3）。
3. 两种交换方式：
   - **点击**：先点一块选中（蓝色高亮），再点另一块完成交换；
   - **拖动**：按住一块拖到目标格子后松手。
4. 所有拼图块归位即胜利，会显示用时和步数。

```
src/

├── main.js
├── styles/main.css              # 全局样式与设计变量
├── composables/

└── components/

    ├── DifficultySelector.vue   # 难度选择
    ├── GameStats.vue            # 计时与步数
    ├── PuzzleBoard.vue          # 拼图棋盘（点击 + 拖拽交互）
    └── WinModal.vue             # 完成提示弹窗
```
